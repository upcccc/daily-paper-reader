## 摘要
水印放射性测试类方法可以检测模型是否在带水印的文档上进行了训练，并已成为大语言模型（LLM）微调中保护数据所有权的关键工具。现有工作已证明其在集中式 LLM 微调中的有效性。然而，这类方法在联邦学习（FL）中面临若干挑战且尚未得到充分探索，而联邦学习是一种广泛应用于在不同用户的私有数据上协作微调 LLM 的范式。FL 主要通过安全聚合（SA）来确保隐私，这允许服务器聚合更新，同时保持客户端更新的私密性。这种机制保护了隐私，但也使得识别哪个客户端在带水印的文档上进行了训练变得困难。在这项工作中，我们提出了 FedAttr，一种用于 FL 的新型客户端级归因协议。FedAttr 通过成对子集差分机制识别哪些客户端在带水印的数据上进行了训练，同时保留了 SA 的隐私保证和 FL 的性能。FedAttr 分三步进行：(i) 通过对两个 SA 查询求差来估计每个客户端的更新；(ii) 通过差分评分利用水印检测器对估计值进行评分；(iii) 通过 Stouffer 方法合并各轮评分。我们从理论上证明，FedAttr 产生了每个客户端更新的无偏估计量，且互信息泄漏有界（即每轮更新为 $O(d^*/N)$）。此外，实验表明 FedAttr 实现了 100% 的真阳性率（TPR）和 0% 的假阳性率（FPR），在 TPR 上至少优于所有基准方法 44.4%，或在 FPR 上优于 19.1%，且相对于 FL 训练时间仅有 6.3% 的开销。消融研究证实 FedAttr 对协议参数和配置具有鲁棒性。

## Abstract
Watermark radioactivity testing type of methods can detect whether a model was trained on watermarked documents, and have become key tools for protecting data ownership in the fine-tuning of large language models (LLMs). Existing works have proved their effectiveness in centralized LLM fine-tuning. However, this type of method faces several challenges and remains underexplored in federated learning (FL), a widely-applied paradigm for fine-tuning LLMs collaboratively on private data across different users. FL mainly ensures privacy through secure aggregation (SA), which allows the server to aggregate updates while keeping clients' updates private. This mechanism preserves privacy but makes it difficult to identify which client trained on watermarked documents. In this work, we propose FedAttr, a new client-level attribution protocol for FL. FedAttr identifies which clients trained on watermarked data via a paired-subset-difference mechanism, while preserving the privacy guarantees of SA and FL performance. FedAttr proceeds in three steps: (i) estimate each client's update by differencing two SA queries, (ii) score the estimate with the watermark detector via differential scoring, and (iii) combine scores across rounds via Stouffer method. We theoretically show that FedAttr produces an unbiased estimator of each client's update with bounded mutual information leakage (i.e., $O(d^*/N)$ per-round update). Moreover, FedAttr empirically achieves 100% TPR and 0% FPR, outperforming all baselines by at least 44.4% in TPR or 19.1% in FPR, with only 6.3% overhead relative to FL training time. Ablation studies confirm that FedAttr is robust to protocol parameters and configurations.

#### 1. 核心问题与整体含义
*   **研究背景**：在大型语言模型（LLM）微调中，数据所有者常通过注入水印（Watermark）来监控数据是否被违规使用。
*   **研究动机**：在联邦学习（FL）场景下，为了保护隐私，系统通常采用安全聚合（SA）机制，这使得服务器只能看到加密后的聚合更新，而无法识别单个客户端的更新。
*   **核心问题**：当全局模型检测到水印信号时，如何在不破坏安全聚合隐私协议的前提下，准确识别出具体是哪个（或哪些）客户端使用了带水印的训练数据。

#### 2. 方法论
FedAttr 协议通过以下三个关键技术步骤实现归因：
*   **客户端更新估计（Paired-subset-difference）**：利用 SA 的子集查询功能，服务器针对目标客户端 $i$ 发起两组配对查询：一组包含 $i$ 的子集聚合，另一组不包含 $i$ 的子集聚合。通过两组查询结果求差，构造出客户端 $i$ 更新的无偏估计量。
*   **差分评分（Differential Scoring）**：由于全局模型在训练过程中会累积水印信号，直接测试估计的更新会导致极高的假阳性。FedAttr 通过计算“估计更新后的模型得分”与“当前全局模型得分”之差，剔除背景噪音，孤立出单个客户端的贡献。
*   **跨轮次 Stouffer 融合（Cross-round Stouffer Combination）**：单轮训练产生的信号较弱且含有估计噪声。协议通过 Stouffer 方法将 $T$ 个通信轮次的差分得分进行统计合并，利用信号随轮次 $\sqrt{T}$ 增长的特性放大显著性。
*   **隐私保证**：论文证明了该估计机制的互信息泄漏量被限制在 $O(d^*/N)$ 范围内（$d^*$ 为有效维度，$N$ 为子集大小）。

#### 6. 主要结论与发现
*   **卓越的检测性能**：FedAttr 在所有标准设置下均达到了 100% 的真阳性率（TPR）和 0% 的假阳性率（FPR），远超现有取证方法。
*   **差分评分的必要性**：实验证明，如果不使用差分评分，即使是明文 Oracle 方法也会因为全局模型的背景偏置产生超过 57% 的误报。

#### 7. 优点
*   **隐私合规**：是首个在不破坏安全聚合（SA）前提下实现 LLM 客户端归因的方案。
*   **统计稳健性**：引入 Stouffer 融合机制，有效解决了联邦学习中单轮更新信号微弱的问题。
*   **即插即用**：对现有的水印检测器（Detector）透明，可作为黑盒函数集成。

#### 8. 不足与局限
*   **依赖所有者参与**：归因过程需要数据所有者提供检测密钥进行评分，服务器无法独立完成闭环审计。
*   **SA 查询压力**：虽然开销较小，但每轮需要额外的配对 SA 查询，在极端大规模或极高频率的联邦任务中可能增加通信负担。
*   **Non-IID 性能波动**：在极端异构（如 Dirichlet $\alpha=0.05$）时，需要显著增加训练轮次才能维持 100% 的准确率。
